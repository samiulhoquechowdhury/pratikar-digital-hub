AI Document Generator (conversational field collection) and AI Chatbot Assistant (RAG over site content, template catalog, course catalog).

- `knowledge-base/` — **built.** Keeps `KnowledgeBaseDocument` in step with published templates, courses and content items (docs/trd.md 4.6). Voyage AI embeddings, pgvector storage, BullMQ queue `knowledge-base-index`.
- `chat/` — **built.** `POST /ai/chat` (public, 10/min per IP): retrieves from the knowledge base with a query-mode embedding, re-reads each hit's live row (published only, current price), and answers with Claude (`claude-opus-5-5` at low effort, server-side refusal fallback on). Returns only the sources the answer cites. `POST /ai/chat/stream` is the same answer as server-sent events (`delta` / `reset` on a fallback / `done` / `error`), which the site uses. The model ends an answer with `[draft]` to offer custom drafting. No key → 503 `AI_NOT_CONFIGURED`, and the site says the assistant is offline.
- `document-fill/` — **built.** `POST /ai/documents/:templateId/fill` (signed in, 20/min): one conversational turn of filling a template. Claude returns answers against a JSON schema built from that template's fields; every value is re-validated with the same rules as `generate()` (`documents/filled-data.ts`), failures are dropped and reported as unclear, and completeness is decided server-side. It never generates — the answers go into the ordinary form for the customer to check.
- `drafting/` — **built.** Drafts a whole custom document from the customer's description (`documents/custom-draft`), or revises one. Runs inside the document-generation worker, never a request: structured output (`DocumentDraft`), medium effort, streamed for the timeout. Blanks are `__________` and listed in `missingDetails`; a request for a deceptive or unlawful document comes back `declined`. A custom draft can only be downloaded once an advocate has reviewed it.
